# Data Directory

## sample_dat_files/
Sample .dat files for testing. Generated by `scripts/create_sample_folder.py`.

## raw/
Place your raw input .dat files here for processing.

## scenario_dataset/

Synthetic scenario inputs generated by `scripts/create_scenario_dataset.py`.
Includes separate folders for empty/missing/zero signals, length mismatches,
signal changes, invalid values/files and a mixed dataset. Select each scenario's
`input/` folder in the GUI. See the generated README and `manifest.json` for the
case list and expected loader behavior. Regeneration instructions are in
`scripts/README.md`.
